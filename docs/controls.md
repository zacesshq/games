# Controls

Every game shares the keys below, so what works in one game works in all of them. Each game's own
keys are added under its name as it arrives.

## Shared keys

| Key | Does |
| --- | --- |
| `Space` | Pauses and resumes. A paused game says so and never loses time |
| `?` | Opens how to play, pausing the game first. `?` or `Esc` closes it |
| Effects volume | Turns the sound effects up or down. The keys are confirmed with the first game |
| Music volume | Turns the music up or down, apart from the effects. The keys are confirmed with the first game |
| Mute | Silences effects and music together and shows that sound is off |
| `Esc` or `Ctrl+C` | Quits and gives the terminal back. `Esc` closes how to play first when it is open |

No key needs Shift, Option or Alt. The mouse is never needed.
