# How to play

Each game's rules in plain words. The same text is on the game's own how-to-play page, behind `?`,
so it can be read here first with a screen reader or a magnifier.

## In every game

- `Space` pauses and resumes at any moment. A paused game never loses time.
- `?` opens how to play and pauses the game while it is open.
- Sound effects and music have their own volumes and one key mutes both. Every sound has a matching
  change on screen.
- `Esc` or `Ctrl+C` quits and gives the terminal back as it was.

The full list of shared keys is in [Controls](controls.md).
