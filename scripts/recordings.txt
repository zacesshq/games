# The keys each game's showcase recording plays, in the order the games appear in the menu.
# `zacess-games snap all --frames N` plays them and scripts/snapshots.sh publishes the frames in
# docs/frames. A recording is changed here, never in the code.
#
# [game]          starts a game's recording
# seed N          the seed it plays with (otherwise 1)
# start S         seconds played before the first frame is kept
# step S keys     presses each key with S seconds after it; right*4 presses one four times
# type S text     types the text one character at a time with S seconds after each
# anything else   keys as for --keys, such as: left, enter, wait:0.5
#
# Times are rounded to the game's 30 steps a second, so 0.133 is four steps and 0.167 five.
